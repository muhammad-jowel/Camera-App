# Camera App

A simple and interactive Camera App that captures photos using the device's camera.

## Features

- Capture photos directly from the app.
- Supports multiple devices with camera access.
- User-friendly interface for easy navigation.

## Live Demo

Check out the live app here: [Camera App](https://camera-app-cyan.vercel.app/)

## Technologies Used

- **Frontend**: React.js
- **Deployment**: Vercel
